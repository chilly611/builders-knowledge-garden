## 3. Permit authority & process

- **Austin Development Services Department (DSD)** issues building permits. Residential Plan Review (1–2 family/small) and Commercial Building Plan Review (commercial/multifamily). ✅
- **Online portal:** Austin Build + Connect (AB+C) — `https://abc.austintexas.gov/`. ✅
- DSD states commercial projects are reviewed "for compliance with the **2024 International Building Code (IBC)** and Building Technical Codes (Local Amendments)." 🟡
- A **Site Plan / Site Plan Exemption** is generally required *before* a building permit. 🟡

## 5. Local legal review required

- **Texas-licensed Architect / Professional Engineer seal** on construction documents (Texas Occupations Code Ch. 1051 architects; Ch. 1001 engineers). ⚠️ *(state law, applies statewide)*
- **DSD plan review + building permit** (and prerequisite **Site Plan**). 🟡
- **Zoning / Land Development Code** compliance (Title 25‑2; incl. Subchapter F "residential design/compatibility"). ✅(listed on DSD codes hub)
- **Flood Hazard Areas** (Ch. 25‑12 Art. 3). ✅
- **Austin Fire Department** review under the 2024 IFC + local amendments. ✅(Fire Building Code link on official page)
- **Texas Accessibility Standards (TAS)** review (commercial). 🟡
- **Energy Conservation Audit & Disclosure (ECAD)** for Austin Energy–served structures. 🟡
- **Historic Preservation** review for structures ~45+ years old (demolition/relocation). 🟡
- **Confirm with local counsel:** the IFGC/fuel-gas question (§2), and the verbatim text/current effective edition of Texas H&S Code Ch. 388. 🔴

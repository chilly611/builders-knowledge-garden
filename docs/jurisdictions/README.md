# Jurisdiction Sourcing Dossiers

Per-jurisdiction sourcing of the **governing body, adopted code(s) + edition/year, permit authority,
official publication URL, and official language**, plus the **local legal review required** and a
**ready-for-implementation** verdict.

**Method / rules followed**
- Official / authoritative (government / standards-body) sources only — no blogs, no codes from memory.
- Every code edition/year is tied to an official URL; any field without an authoritative source is marked
  `UNVERIFIED — needs local counsel/sourcing`, never guessed.
- Verdict criterion = *are the required sourcing fields authoritatively confirmed?* — separate from the
  always-required local legal review for any specific build.
- Compiled 2026-05-31. **Not legal advice.**

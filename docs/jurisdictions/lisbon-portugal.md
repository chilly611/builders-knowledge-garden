## 3. Permit authority & process

- **CML** controls building works via **licenciamento** (licence) or **comunicação prévia** (prior notification), per the RJUE; submissions through CML's *Urbanismo Digital* / Loja Lisboa. 🟡
- Instructory elements set by **Portaria n.º 71-A/2024** (revoking Portaria 113/2015); mandatory models in **Portaria n.º 71-B/2024**. 🟡
- **Lisbon-specific:** since **1 April 2023**, a **Seismic Vulnerability Assessment Report** must accompany the architecture project (under **Portaria n.º 302/2019**). 🟡
- **PDM de Lisboa** governs land use (zoning, índices, heights); consult via *Lisboa Interativa* before submitting. 🟡

## 5. Local legal review required

- **Project by an enrolled professional** — architect (**Ordem dos Arquitectos**) / engineer (**Ordem dos Engenheiros**), per Lei 31/2009 (am. 40/2015). 🟡
- **CML licenciamento or comunicação prévia** (RJUE) via Urbanismo Digital. 🟡
- **Seismic Vulnerability Report** with the architecture project (Portaria 302/2019) — Lisbon mandatory since 2023-04-01. 🟡
- **Fire-safety project** under SCIE (DL 220/2008 + Portaria 1532/2008); approval/coordination with the national civil-protection authority (ANEPC). 🟡🔴 *(ANEPC procedural page not reachable; confirm workflow)*
- **PDM / RMUEL / heritage (Carta Municipal do Património) / ARU** compliance for the specific parcel via *Lisboa Interativa*. 🟡🔴
- **Energy pre-certificate (SCE)** at licensing and final certificate at use authorisation. 🟡
